# 世界观察 · 每日深读

公开阅读网页：全球经济、货币、金融、战争与地缘政治报告精选。

每条包含一句直接结论、来源链接及实际判断价值，区分来源发现与分析推断。按日期归档，支持主题筛选和搜索；没有合格的新内容时不凑数量。

## 更新方式

每天北京时间 09:00，现有云端研究任务检索并核验新资料。GitHub Actions 每约 15 分钟同步一次已完成归档，并发布 GitHub Pages。GitHub 定时运行可能延迟，09:00 是研究启动时间，并非保证发布完成时间。

研究归档服务仍使用原有私有 Sites 后端；网页与公开阅读数据位于此仓库。Actions 的 SITES_AUTH_TOKEN 保存于仓库 Secrets，源码与网页不包含凭证。服务请求失败或数据校验失败时工作流失败，上一版公开网页保留。

## 本地开发

运行 `npm ci` 和 `npm run build`，静态文件输出至 dist。已发布的历史数据保存在 public/data/briefs.json。

内容来源为各原始发布机构；本网站只提供简短分析与原文链接。
